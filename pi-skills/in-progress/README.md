# In progress

Pi-adapted in-progress skills from upstream. These are useful enough to try in pi, but they may still change more often than promoted engineering or productivity skills.

## User-invoked

- **[batch-grill-me](./batch-grill-me/SKILL.md)** — Grill every currently unblocked decision in rounds rather than one question at a time.
- **[loop-me](./loop-me/SKILL.md)** — Grill workflow loops into implementable specs under `workflows/*.md`.
- **[setup-ts-deep-modules](./setup-ts-deep-modules/SKILL.md)** — Enforce TypeScript package interfaces with dependency-cruiser and provide a tested pattern for other stacks.
- **[to-questionnaire](./to-questionnaire/SKILL.md)** — Turn a knowledge gap into a discovery questionnaire for one recipient.
- **[wizard](./wizard/SKILL.md)** — Generate an interactive bash wizard for a manual setup, migration, or state transition.
